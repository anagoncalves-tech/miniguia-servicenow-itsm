# Glossário: ServiceNow ITSM e Incident Management

|           Termo              |                                           Definição                                                    |
|------------------------------|----|
| ITSM                         | Gerenciamento de Serviços de TI. Conjunto de práticas para entregar e melhorar serviços de tecnologia. |
| ServiceNow | Plataforma digital usada para automatizar processos e fluxos de trabalho corporativos. |
| ITSM Module | Conjunto de funcionalidades do ServiceNow voltadas para gestão de serviços de TI. |
| Incident | Interrupção ou degradação não planejada de um serviço. |
| Incident Management | Processo responsável por restaurar a operação normal de um serviço o mais rápido possível. |
| SLA | Acordo de Nível de Serviço que define prazos para atendimento e resolução. |
| Impact | Mede o quanto o incidente afeta o negócio ou os usuários. |
| Urgency | Mede a rapidez necessária para resolver o incidente. |
| Priority | Prioridade definida com base na combinação de impacto e urgência. |
| Assignment Group | Grupo responsável pelo atendimento de um chamado. |
| Caller | Usuário que abriu ou reportou o incidente. |
| Short Description | Resumo curto do incidente. |
| Description | Campo usado para detalhar o problema reportado. |
| Category | Classificação principal do incidente. |
| Subcategory | Classificação mais específica do incidente. |
| Resolution Notes | Campo onde é registrada a solução aplicada. |
| Knowledge Base | Base de conhecimento com artigos e procedimentos reutilizáveis. |
| Problem Management | Processo usado para investigar causas raiz de incidentes recorrentes. |
| Change Management | Processo usado para controlar mudanças em serviços ou sistemas. |
| CMDB | Base de dados que armazena informações sobre itens de configuração. |
| CI | Configuration Item, ou item de configuração, como servidor, aplicação ou serviço. |
| Service Desk | Primeiro ponto de contato para suporte aos usuários. |
| Backlog | Conjunto de chamados pendentes de atendimento ou resolução. |
| Reopened Incident | Incidente reaberto após ter sido considerado resolvido. |
