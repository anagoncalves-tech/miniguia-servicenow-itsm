# Miniguia de Estudos: ServiceNow ITSM

## Tema

ServiceNow ITSM: fundamentos, processos e boas práticas para gestão de incidentes.

## Contexto

Este projeto foi desenvolvido como parte de um desafio prático da DIO, com o objetivo de criar um caderno temático utilizando Inteligência Artificial como ferramenta de apoio à aprendizagem ativa.

O estudo tem como foco o ServiceNow ITSM, especialmente o processo de Incident Management, abordando conceitos fundamentais, etapas do processo, boas práticas, glossário e prompts reutilizáveis.

## Objetivos

- Compreender os fundamentos de ITSM.
- Entender como o ServiceNow apoia a gestão de incidentes.
- Estudar o ciclo de vida de um incidente.
- Identificar boas práticas para registro, priorização, atendimento e encerramento.
- Criar um material de apoio para estudos futuros.
- Demonstrar o uso de IA na organização e consolidação do conhecimento.

## Resultado Final

O resultado final é um caderno temático sobre ServiceNow ITSM e Gestão de Incidentes, organizado para consulta rápida, revisão de estudos e composição de portfólio profissional.
